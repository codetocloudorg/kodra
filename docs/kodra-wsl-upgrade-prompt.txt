### Critical rendering rules (LEARNED THE HARD WAY):
- Use `echo -e` with hardcoded strings, NOT `printf %b` with dynamic padding
- printf's `%*s` counts BYTES not display columns — breaks with Unicode
- █ (U+2588 FULL BLOCK) renders DOUBLE WIDTH in many terminal fonts
- Do NOT use closed box borders (┌┐└┘ or ╭╮╰╯) around ASCII art
- Use horizontal separators ━━━ only (top and bottom)
- Detect NO_COLOR env var and non-TTY (`[ ! -t 1 ]`) for plain-text fallback
- Test in Windows Terminal, Ghostty, and basic xterm

```bash
echo -e "  ${C_DIM}  Run ${C_CYAN}kodra repair --all${NC}${C_DIM} to fix any issues${NC}"
```

## 2.6 — Copy Buttons on All Code Blocks

Add to every `<pre>`, `.code-block`, and `.install-command`:
```javascript
document.querySelectorAll('pre, .code-block, .install-command').forEach(block => {
  if (block.querySelector('.copy-btn')) return;
  const btn = document.createElement('button');
  btn.textContent = 'copy';
  btn.className = 'copy-btn';
  btn.setAttribute('aria-label', 'Copy to clipboard');
  btn.addEventListener('click', () => {
    const code = block.querySelector('code')
      ? block.querySelector('code').innerText.trim()
      : block.innerText.replace(/copy(ed!)?$/m, '').trim();
    navigator.clipboard.writeText(code);
    btn.textContent = 'copied!';
    btn.classList.add('copied');
    setTimeout(() => { btn.textContent = 'copy'; btn.classList.remove('copied'); }, 2000);
  });
  block.style.position = 'relative';
  block.appendChild(btn);
});
```

```yaml
name: Website Tests
on:
  push:
    branches: [main]

  pull_request:
    branches: [main]

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
      - run: npx playwright install --with-deps
      - run: npx playwright test
      - uses: actions/upload-artifact@v4
        if: failure()
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 7
```

## 5.2 — .github/workflows/ci.yml (Shell Script Validation)

Create a basic CI that validates shell scripts on every push:

```yaml
name: CI
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  shellcheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install ShellCheck
        run: sudo apt-get install -y shellcheck
      - name: Check shell scripts
        run: |
          find . -name "*.sh" -not -path "./.git/*" -not -path "./node_modules/*" | while read f; do
            echo "Checking $f..."
            shellcheck "$f" || true
          done
      - name: Syntax check all scripts
        run: |
          ERRORS=0
          for f in $(find . -name "*.sh" -not -path "./.git/*" -not -path "./node_modules/*"); do
            bash -n "$f" || ERRORS=$((ERRORS + 1))
          done
          exit $ERRORS
```

# PHASE 8: COPY CONVENTIONS AND STANDARDS
# ============================================================================

## CLI naming rules:
- In code blocks: always lowercase `kodra`
- In prose: always "Kodra" (capitalized brand name)
- Never "KODRA" or "kodra" mid-sentence
- The install output says "Run `kodra doctor` to verify" — keep this everywhere

## "Agentic" usage rules:
- Use MAX 3 times on the page:
  1. Badge row: `wsl2-native` badge (or `agentic-first`)
  2. Last line of hero subtitle: "This is agentic engineering — done for you."
  3. Footer tagline: keep as-is
- NEVER use "agentic" in <title> tag
- NEVER lead a section with it

## Shell script standards (for any scripts modified):
```bash
#!/usr/bin/env bash
set -e
KODRA_DIR="${KODRA_DIR:-$HOME/.kodra}"

# Functions use snake_case
# Local variables use lowercase
# Global variables use UPPERCASE
# Check commands with `command -v`, not `which`
# Use `local` for function variables
# Scripts must be idempotent (safe to run multiple times)
```

## Do NOT:
- Reference GitHub Copilot in commit messages as a development tool
- Use Cursor editor references (use VS Code)
- Use `sudo` unless absolutely necessary
- Hardcode paths (use $HOME, $KODRA_DIR)
- Use `eval` with user input
- Store credentials in config files
- Add light mode as default (dark-first always)
- Use rounded pastel UI cards
- Use purple gradients on white backgrounds
