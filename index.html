Questions

Frequently Asked

What Ubuntu versions are supported? +

Kodra is designed for Ubuntu 24.04 LTS and newer. It also works on Ubuntu in WSL2 for Windows users. Ubuntu 22.04 may work but is not officially supported.

Is an Azure subscription required? +

No. Kodra installs the Azure tools, but you can use them with any subscription (or no subscription). The Docker, Kubernetes, and terminal features work completely standalone. You can even skip Azure tools entirely with --skip-azure.

Will it break my existing setup? +

Kodra backs up your existing dotfiles (bashrc, zshrc, gitconfig, etc.) before making changes. You can restore them anytime with kodra restore. It's designed to be safe on existing systems.

Can I customize what gets installed? +

Yes! The installer has an interactive prompt for optional apps. You can also use flags: --skip-azure, --skip-docker, --minimal for terminal-only setup.

How do I uninstall Kodra? +

Run kodra uninstall for interactive removal. You can uninstall specific components or everything. Kodra can restore your original dotfiles during uninstall.

Is it free and open source? +

Yes! Kodra is completely free under the MIT license. The code is on GitHub. Contributions are welcome!

Why Ubuntu? +

Ubuntu offers the best balance of stability, community support, and developer experience. With 40M+ users, a low learning curve, first-class Azure VM and WSL support, and 5 years of LTS security updates, it’s the ideal foundation for cloud-native development. Kodra supports Ubuntu 24.04+ (Noble Numbat LTS) and WSL Edition is also available.
